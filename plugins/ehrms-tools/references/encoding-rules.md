# EHRMS 檔案編碼處理規則

## 核心原則

本專案後端 VB6 檔案（.cls / .bas）原始編碼為 **ANSI/Big5**（非 UTF-8）。

## 必須遵守的規則

1. **不改變檔案原始編碼**：修改檔案後維持原本的編碼格式儲存
2. **不使用任何轉碼工具**：禁止使用 PowerShell、cmd、iconv、chcp、sed 等轉碼指令或腳本
3. **文字層面思考**：直接以繁體中文撰寫，假設在 Big5 環境下可正常顯示
4. **讀取時切換編碼**：優先用 IDE 重新開啟並切換編碼（Big5/ANSI），檔案過大則改用分段閱讀

## 受影響與不受影響的部分

**不受編碼影響**（可直接分析）：
- VB6 關鍵字（Public, Function, Sub, Dim 等）
- 變數名稱、函式名稱（英文）
- 程式碼邏輯結構、SP 呼叫、參數傳遞

**受編碼影響**（可能顯示亂碼）：
- 中文註解（`'` 開頭的註解行）
- 中文字串常量
