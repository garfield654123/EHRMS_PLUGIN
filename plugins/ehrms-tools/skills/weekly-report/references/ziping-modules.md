# 模組分類關鍵字規則（範例）

週會報告中「模組分類」欄位的對應規則。
依 Jira 標題關鍵字自動歸類，若同一張票符合多個模組，以最具體的為主。

## 模組清單與關鍵字

| 模組名稱 | 關鍵字（標題中包含即歸類） |
|----------|--------------------------|
| M1 | M1、人事、在職、離職、到職、異動、轉調、試用期、派駐、人員資料 |
| M8 | M8、薪資管理、薪資計算、薪資匯出 |
| 育嬰留停 | 育嬰、留停、育嬰留停 |
| 通知信 | 通知信、通知郵件、mail、email、寄信 |
| Portal後臺 | Portal、門禁、portal後臺 |
| 資安 | 資安、Security、掃描、漏洞、RITM |

## 使用說明

- 對每張 Jira 票的標題進行關鍵字比對（不分大小寫）
- 若無法對應任何模組，標記為「未分類」並列出，請使用者手動指定
- 輸出格式：`M1:N、育嬰留停:N、資安:N`（票數為 0 的模組可省略，或依使用者習慣保留）

## 注意

此規則為個人職務範例。請依你自己的模組分工調整，或新增對應的 references 檔案。
